## MapBiomas Agua Uruguay 
   ##Colección 1

La **Colección 1 de MapBiomas Agua Uruguay** genera una serie temporal mensual de agua superficial con una resolución espacial de **30 m** para el período **1985–2025**, así como productos anuales derivados, con cobertura de todo el territorio nacional.

El flujo de trabajo sigue la metodología desarrollada por la red MapBiomas Agua (Souza et al., 2019), basada en la clasificación a nivel de subpíxel de imágenes Landsat mediante **análisis de mezcla espectral**, **lógica difusa** y **relleno temporal de vacíos de información**. El procesamiento se realiza en **Google Earth Engine**.
